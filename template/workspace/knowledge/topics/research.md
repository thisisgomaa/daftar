## Lessons
- 2026-11-09 [daftar] Summaries soften concessions: go back to the raw transcript before any money or commitment decision.
- 2026-11-09 [daftar] Verify a link by reading the page content, not the status code; a 200 can be a generic fallback page.
- 2026-11-09 [daftar] Disqualifying requirements often hide in attachments; read every attachment before judging fit.
- 2026-11-09 [daftar] For a complete inventory, combine the live source (e.g. a store API) with web archive snapshots; local lists miss retired items.
- 2026-11-09 [daftar] Before diagnosing an integration outage, ask the platform for its own status and limits; silent logs can be a deliberate protective pause.
- 2026-11-09 [daftar] When a metric's filter changed on a given date, compare across that date only with the same filter applied, or you will see fake trends.
