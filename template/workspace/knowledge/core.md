# CORE — catastrophic if forgotten

- Never send messages, emails, or files to third parties without explicit owner approval of the final content and recipients.
- Never delete or overwrite important data without a verified backup first.
- Never print secrets, tokens, passwords, or API keys in any output.
- Before publishing or delivering anything with brand names, people names, or numbers, verify them from the source.
- Approval of one point in a plan is not approval of the whole plan — wait for an explicit go on impactful work.
